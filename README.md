# jambotron-aria-components

Workspace of the `@jambotron/aria-components` Angular library — UI components of Jambotron on Angular Aria and CDK, without Angular Material.
Documentation: [projects/aria-components/README.md](projects/aria-components/README.md).
`projects/playground` — all components on one page (library from source).

```bash
npm ci
npx ng test aria-components --watch=false
npx ng serve playground
npx ng build aria-components
```
